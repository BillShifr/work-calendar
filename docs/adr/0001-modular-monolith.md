# ADR-0001: модульный монолит

Статус: принят, 2026-10-29.

## Решение

Next.js-приложение, доменные модули и фоновые операции поставляются одним продуктом и используют одну PostgreSQL 18. Внутри кода разделены auth, people, overtime, vacation, approval, notifications и audit. Связь между ними идёт через типизированные сервисы и транзакционный outbox.

## Причины

Для текущей нагрузки микросервисы увеличат операционную сложность без выигрыша. Монолит обеспечивает простые транзакции, единый аудит и быстрый выпуск. Границы модулей оставляют возможность позднее выделить компонент по измеренным причинам.

## Следствия

Запрещены прямые зависимости UI от таблиц и предметная логика в route handlers. Изменения состояния проходят доменные сервисы, permission check, транзакцию, ревизию и audit event.
