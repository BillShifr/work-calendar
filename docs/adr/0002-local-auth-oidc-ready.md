# ADR-0002: локальная авторизация с готовностью к OIDC

Статус: принят, 2026-10-29.

До подключения корпоративного IdP используется логин и Argon2id. Сервер хранит только хэш непрозрачного session token; cookie `HttpOnly`, `SameSite=Lax`, в production — `Secure`. Таблица identity отделена от профиля сотрудника, поэтому OIDC subject можно подключить без миграции предметных данных.
