# UI-система HR

Этот контракт обязателен для всех экранов продукта. Локальные компоненты не должны вводить собственную шкалу размеров без зафиксированной причины.

## Базовые библиотеки

- `Radix Primitives` — переключатели, сегментированный выбор и списки. Нативные системные checkbox/select и самописные тумблеры запрещены.
- `Lucide React` — стрелки, плюс/минус, закрытие, поиск, сохранение и остальные служебные пиктограммы.
- `Motion` — пружинная обратная связь на нажатие и подтверждённая сервером анимация отправки. При `prefers-reduced-motion` движение заменяется короткой сменой состояния.
- `Golos Text Variable` — единственный основной шрифт продукта, поставляется вместе с приложением.

## Типографика

| Роль               | Размер   | Применение                                  |
| ------------------ | -------- | ------------------------------------------- |
| Основной текст     | 16 px    | значения, кнопки, содержимое форм и списков |
| Подпись            | 15 px    | подписи полей, статусы, метаданные строк    |
| Вторичный текст    | 14 px    | даты, легенды, вспомогательные значения     |
| Крупный текст      | 18 px    | выбранные периоды и основные значения       |
| Заголовок страницы | 26–32 px | один главный заголовок экрана               |

Текст меньше 14 px запрещён. Исключений для таблиц и календарей нет: плотность достигается компоновкой, а не уменьшением шрифта.

## Интерактивные элементы

- Основная высота кнопки, поля, списка и числового контрола — 44 px.
- Компактная высота навигации и фильтров — 40 px.
- Кликабельная зона календарной ячейки — не меньше 44×44 px на узком экране.
- Переключатель имеет кликабельный трек 68×44 px и читаемую подпись рядом.
- Числовые значения меняются крупными кнопками `−` и `+`; системный spinner запрещён.
- Нативный checkbox без оформленной кликабельной строки запрещён.
- Основное действие имеет один устойчивый акцентный цвет; вторичные действия остаются нейтральными.

## Отступы и компоновка

Базовая шкала: 8, 12, 16, 24 и 32 px.

- Между крупными секциями — 12–16 px.
- Внутренний отступ рабочей секции — 12–20 px.
- Между подписью и полем — 8 px.
- Строка реестра — 56–60 px; подробная форма раскрывается только для выбранной записи.
- Панель календарных действий — 64–76 px в зависимости от доступной высоты.
- Формы не размещают более трёх полей в ряд; на узких экранах перестраиваются в одну колонку.

## Общие состояния

- Фокус: сплошная обводка 3 px, видимая на кнопках, ссылках, полях, списках и textarea.
- Disabled: элемент остаётся читаемым, но явно теряет акцент и курсор действия.
- Ошибка: красный используется только для ошибки или конфликта.
- Успех: зелёный используется только для утверждённого состояния.
- Правка кадровика: фиолетовый сохраняется во времени и отпусках.
- Интерактивный синий применяется только для действия, текущего выбора и пользовательских данных.
- Янтарный применяется для состояния, требующего внимания, но не являющегося ошибкой.
- Информация не должна выглядеть как кнопка, если она не выполняет действие.

## Адаптив календарей

- Месячный календарь внеурочного времени всегда использует семь колонок и не создаёт горизонтальный скролл.
- Матрица отпусков 12×31 показывается целиком только при ширине, на которой числа остаются читаемыми.
- До 1500 px матрица автоматически заменяется календарём одного месяца с семью колонками и теми же данными/действиями. Это не отдельный упрощённый сценарий.
- При высоте 768 px строки обоих календарей вычисляются от viewport и полностью помещаются без внутреннего или горизонтального скролла; минимальная зона дня остаётся 44 px.

## Проверка нового интерфейса

Перед завершением UI-изменения необходимо проверить:

1. Desktop и мобильный viewport.
2. Масштаб 200% без потери действий.
3. Клавиатурный фокус и последовательность Tab.
4. Высоту всех действий и читаемость вторичного текста.
5. Отсутствие нативных `number` spinner и мелких checkbox.
6. Одинаковые названия и визуальный приоритет одинаковых операций на разных экранах.
